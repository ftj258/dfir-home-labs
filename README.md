# DFIR Home Labs

I love solving mysteries, so every lab here is a case: a digital crime scene, evidence to collect and verify, and a question to answer. I name them after Ace Attorney cases because that's how investigating feels to me.

## Cases

| Case | What happened | Evidence | Tools |
| --- | --- | --- | --- |
| [Case 1: Turnabout Memories](01-memory-forensics/turnabout-memories/) | A computer crashed with something hidden in memory | Windows 7 memory image (MemLabs Lab 1) | Volatility 3, Volatility 2.6 |
| [Case 2: Turnabout Spreadsheet](02-disk-timeline-analysis/turnabout-spreadsheet/) | A confidential company spreadsheet ended up online | Windows XP disk image (M57-Jean) | Autopsy |

More cases are in progress and will show up here when they're finished.

## Lab setup

- [Oracle Cloud A1 retry script](cloud-lab-setup/) - PowerShell script I wrote to keep retrying a free Oracle Cloud instance launch through "Out of host capacity" errors

## Why these labs

My professional work is federal incident response and digital forensics - these labs are additional,
self-directed practice using public datasets and tools, done to build and demonstrate skill in areas
beyond my day-to-day scope.
